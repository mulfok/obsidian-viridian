## Fonts
Viridian bundles its hand-picked fonts for your use offline (and on mobile!). Besides that, here are configurations I recommend, which you can change using **Style Manager.**

**Serif Mode (Work)**
Body: Lora
Header: Fraunces
Monospace: Victor Mono
Interface: Inter

**Sans Mode (Play)**
Body: Manrope
Header: Lexend
Monospace: Victor Mono
Interface: Inter

**Classic Mode (2022 Edition!)**
Body: Source Serif Pro (Not included)
Header: Brevia (Not included)
Monospace: Victor Mono
Interface: Victor Mono

## Transparency
As far as I know, Obsidian does not currently provide an easy way to have a transparent window, and it falls to the user to set it up on their system instead.

On Linux, I personally use my window manager's compositor effects to make Obsidian around 20% transparent, along with some background blur. For this, I recommend using the **OLED** theme (which I made specifically for this) through **Style Manager.**
